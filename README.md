- **AIAdoptionHospitals** — a random forest on 292,000 Medicare billing records predicting which hospitals sit in AI-adoption hotspots, and how coding intensity differs by DRG family.

- **ourademo** — an Oura ring data dashboard.

**Hardware and ML** (on [ellaetchandy.com](https://www.ellaetchandy.com/)): a rate-adaptive VVIR pacemaker (analog front end, Arduino, C++), U-Net mammogram segmentation, sleep EEG spectral analysis.

**Now, with teams**
- **Coast Guard exposure logger** (BME 473, medical device design) — a head-worn wearable for boat crews that logs whole-body vibration and impact exposure from an IMU, so a coxswain can decide when a crew has had enough. Team of five; between design inputs and first prototype.
- **AI adoption and Medicare billing** (BME 304, data science) — with two teammates, a random forest on 292,000 CMS inpatient records predicting whether a hospital sits in an AI-adoption hotspot, then comparing coding intensity by DRG family between hotspots and coldspots. Built on the BCBSA finding that AI coding tools added $942M in costs for similar care.
